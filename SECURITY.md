# Security Policy

## Supported versions

Security fixes are released for the latest published version of the `cubix-ui` CLI and for the current registry served from https://cubixflow.ir/r.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/aminebdali1992/cubix-design-system/security/advisories/new). Include:

- The affected package, component, or registry item and its version
- Steps to reproduce, or a proof of concept
- The impact you expect

Reports are acknowledged as soon as they are reviewed. Once the issue is confirmed, a fix is prepared privately and released, and the advisory is published with credit unless you prefer to stay anonymous.
